## Hacker News

**Title**

Show HN: LaunchPane – a native, open-source Launchpad replacement for macOS

**Post**

I built LaunchPane, a native macOS app launcher for people who want the familiar full-screen grid, folders, search, and persistent app organization.

It is written in Swift 6 with AppKit and Core Animation using documented macOS APIs. The layout adapts to different displays and scaling modes, supports keyboard navigation and Reduce Motion, and keeps everything local—there are no accounts, telemetry, or required network services.

The current release supports Apple silicon Macs on macOS 15 or later. The downloadable build is not yet notarized, so macOS requires the one-time “Open Anyway” step documented in the README.

I would especially appreciate feedback on interaction feel, unusual display configurations, and accessibility.

Source and download: https://github.com/LuckyFishOno/launchpane

## Reddit r/macapps

**Title**

I made LaunchPane, a free and open-source native Launchpad replacement for macOS

**Post**

LaunchPane is a full-screen Mac app launcher with instant search, folders, drag-and-drop organization, cross-page dragging, and smooth trackpad/keyboard paging.

I built it natively in Swift 6 with AppKit and Core Animation. It uses documented system APIs, stores the layout locally, and has no telemetry, account, activation, or mandatory network connection.

Current requirements: macOS 15 or later and an Apple silicon Mac. The release is not notarized yet, so the README explains the one-time Privacy & Security step required by macOS.

Screenshot, source, and download: https://github.com/LuckyFishOno/launchpane

Feedback is very welcome, particularly from anyone using multiple displays or non-default scaling.
